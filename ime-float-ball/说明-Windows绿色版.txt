输入法悬浮球 · Windows 绿色版
================================

一个常驻桌面的圆形小图标，点一下就切换输入法。
绿色版 = 免安装：不写注册表、不装服务、配置文件就在程序旁边，
把整个文件夹拷走（U 盘/网盘）到别的 Windows 电脑上照样能直接双击运行。


一、怎么用
----------
1) 双击「输入法悬浮球.exe」。
   桌面上会出现一个蓝色圆形图标（默认在屏幕右上角）。
2) 左键点圆的「中上部」 → 切到下一个输入法（循环）。
3) 左键点圆的「下边缘」   → 打开便签（悬停在该区域时底下会亮一条白弧）。
4) 右键圆球             → 菜单：切换输入法 / 图标大小 / 设置 / 便签 / 隐藏 / 退出。
5) 滚轮                      → 实时调节透明度。
6) 按住拖动                  → 挪位置，松手自动记住。
7) 任务栏右下角托盘里有个小图标，球被隐藏后可以点它找回来（单击/右键都会弹菜单）。

首次运行会自动生成 data\config.json，记录你的位置、大小、透明度、启用的输入法等。


二、图标大小
------------
· 右键 → 「图标大小」→ 小 56 / 标准 84 / 大 108 / 特大 132，选完立即生效。
· 右键 → 「设置」→ 图标大小滑块，可在 40 ~ 160 像素之间无级调节。


三、设置项（右键 → 设置）
------------------------
· 整体透明度（1~100）
· 图标大小（40~160 px，带 4 个快捷档位）
· 图标背景：选图片（自动裁成圆形）/ 清除图片 / 纯色
· 左键循环切换哪些输入法（至少勾两个才会循环；只勾一个等同全选）
· 开机自动启动（会在「启动」文件夹放一个快捷方式，不写注册表）
设置里改透明度/大小是实时预览：点「确定」才保存，点「取消」会还原。


四、切换的到底是什么？
----------------------
Windows 里「输入法」在系统层面就是一组键盘布局（HKL），
Win + Space 循环切换的正是这一组，本工具枚举和切换的也是同一组，
所以列表顺序、能切到的条目都与 Win + Space 完全一致，
包括「英语(美国)」「中文(简体) - 微软拼音」「搜狗拼音」等。


五、常见问题
------------
Q1. 点了球没反应 / 切不过去？
    ① 先右键球 → 设置，确认至少勾选了两个输入法。
    ② 如果你正在操作的窗口是「以管理员身份运行」的程序（任务管理器、某些安装包等），
       Windows 的 UIPI 机制会拦截普通权限程序发给它的消息，此时切换无效。
       解决办法：右键球 → 退出，然后右键 输入法悬浮球.exe →「以管理员身份运行」。
    ③ 某些全屏游戏会独占键盘，也会拦截消息，属正常现象。

Q2. 杀毒软件/Windows Defender 报毒？
    PyInstaller 打包的 exe 常被误报（启发式），本程序完全开源可查（Python 源码就在
    开发目录里）。选择「保留」或把文件夹加入白名单即可。

Q3. 开机自启放在哪？
    %APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\输入法悬浮球.lnk
    在设置里取消勾选会自动删掉，不会残留。

Q4. 配置想放到别处？
    设环境变量 IMEFLOAT_DATA 指向任意目录即可（优先级最高）。
    程序目录不可写时（例如放进 C:\Program Files）会自动退到
    %APPDATA%\输入法悬浮球\。

Q5. 双击后要等一两秒才出现？
    单文件 exe（--onefile）每次启动都要解压到临时目录，属正常。
    想启动更快，可以在打包时把 build_win.bat 里的 --onefile 换成 --onedir，
    会输出一个文件夹，启动几乎瞬间，且更不容易被杀毒软件误报。

Q6. 想从源码运行（不打包）？
    装好 Python 3.9+ 与 PyQt6 后，双击「启动-无控制台.vbs」即可（不会弹黑框）。
    或者命令行： pythonw ime_float.py


六、卸载
--------
1) 右键球 → 退出；
2) 删掉整个绿色版文件夹即可，不留任何垃圾。
   （若开过开机自启，请先在设置里取消勾选，或手动删掉上面 Q3 那个快捷方式。）
